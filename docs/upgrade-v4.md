# V4：视线、道路、电缆与门口署名

用户反馈：部分设备近景仍被前景建筑遮挡；便利店压占车道；送出电缆穿过店体；在门口地面添加艺术英文 Designed by LAP。

## 根因与修正

- 原有镜头只检查目标的取景范围，未检查目标与相机之间的实物。增加多个候选角度的真实几何视线检测，以及观察时的前景透视。目标保持实体，挡住它的设备使用独立材质淡出；总览、关闭透视、切换目标、隔离观察均恢复原材质和阴影。拖动镜头也重新检测。
- 门店原安装位置使前场与停车挡块落入车道。将门店向场内退后，拆除车道内挡块，门店实体、路缘和路灯保留在人行前场内。道路与门店共用 site-layout.js 坐标。
- 原接线箱及管道位于店体内部。改为店外独立接线柜，主电缆沿侧方抵达柜体，短导管止于侧墙密封进线口。电流动画与实物电缆使用相同折线路径。
- 门口地面加入离线生成的书法字体署名，保留精确大小写 Designed by LAP，并加入细笔收尾装饰。深色笔迹与暖光铺装保持对比。

## 验证要求

除原有能量、束线和灯光测试外，检查所有候选视角的桌面/手机取景范围、真实电厂的遮挡残留、材质与阴影恢复、供电状态同步、门店全部实体与道路的间距、全段电缆和流动标记的几何间隙、接线柜端口，以及署名的朝向和可读性。
