# V3：束流、观察与负载

用户要求：查证中性束加热；改善步骤与部件视角并闪亮两次；补充关键物理原理；末端改为 7‑Eleven 风格便利店，清楚显示暖光供电。

实施约定：

- 保留九个相连系统、整厂/能量回流/拆解模式以及所有离线运行能力。
- NBI 参照 ITER / MITICA 的负离子方案：束源与加速栅、中性化器、残余离子清除器、可打开的量热计、直线漂移束道。带电剩余离子偏转进入吸收板，中性束沿直线切向注入；进入等离子体后再电离并传能。工业几何是科普缩比。
- 观察方向由 inspection.js 或部件 userData.inspection 扩展；镜头停稳后用独立覆盖层强调选中实物两次，不改共享材质。减少动态模式使用静态强调。
- 原理资料由 principles.js 驱动；每个系统均有公式、解释和可追溯官方资料。
- 暖光负载必须满足发电机已建立且净输出为正。第九步默认暮色，可切回白天；功率不足时关闭灯具、光晕和地面光斑。

验证：Node 数据、物理顺序、能量与灯光状态测试；浏览器检查步骤 1–4、束流子部件、关键原理与便利店供电明暗对照；重新生成单文件离线入口和源码包。
